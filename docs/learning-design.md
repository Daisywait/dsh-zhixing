# 学习流程校正依据

本文件是知行对《学习观》（于建国）的方法概述与产品决策，不是原书摘录。页码按348页扫描件标注，正文 PDF 页码比书内页码大4。2026-09-06 已完成全书34章的 OCR 底本通读并核对关键原图，不等于全书逐字校勘。下列各项区分理论依据与软件实现；通读不意味着软件已经完整实现全部理论。

## 本轮修正

第5、16、20章说明下上脱节和判联错配；第23章区分理解错误、材料错误与原模型局限；第29章说明认知适配；第34章将这些组织为诊断循环。本轮增加可选 diagnosis：记录缺口、判断依据、材料选择，以及真实作答引用。没有作答时明确标记暂定判断或自述，不生成成绩。工具验证引用和保存历史，判断本身仍需助手核实。

学习页直接呈现完整例子，可切换同模型实例或不同模型材料，再对照当前规则。用户可以请求拆开讲解或核查有争议的材料，草稿携带当前实例和规则。不把求助、质疑或切换例子记为错误作答。原有档案无诊断字段时仍然可用，后续学习时逐步建立依据。

桌面 dsh 是当前唯一产品目标；验证桌面与桌面嵌入布局。暂不扩展手机体验。现阶段仍由助手遵守规则来区分教学与验证，程序没有自动判定一个案例是否真正未见；也没有宣称新增的诊断字段就是可靠的认知测量。

## 已纠正的产品假设

- “第0层到第4层依次通过”没有作为原书统一流程的依据，现已移除。
- “每一轮先出题”和“任何答案都不能提前讲”混淆教学例子与验证材料。
- “只能用学习者自己举的例子”把提供学习材料的负担转给了初学者；允许明确标注的助手教学例子。
- 面板继续入口不再限定“继续练一题”，支持继续学习、请求讲解、换例子和主动验证。
- 现有档案的旧下一步会交给助手重新评估，不批量覆盖真实档案。

## 产品约定与限制

一次一个待答问题、草稿由用户发送、24小时延后复测和证据状态是产品约定，不是原书实验结论。读过规则后独立解决另一个新情况可以记录为独立作答；看过同题答案再答不可以。

当前使用已有 diagram.pairs 呈现材料，不增加档案版本。页面展示的材料只应是已揭示的示例；正在进行的测验仍在 dsh 对话中。助手需按技能要求避免提前写入待答题答案，程序尚不能自动判定材料是否真的“未见”。

自动测试可以检查界面动作、协议与提示是否接通，不能证明语言模型必然遵循教学要求，也不能证明教学有效。用实际对话验收：

| 场景 | 期望 |
| --- | --- |
| “我完全不懂条件概率” | 短讲解配可理解的教学实例，不要求先说出输入输出 |
| 已提供明确教材片段 | 直接加工片段，仅问影响理解的缺失信息 |
| “先讲给我听” | 给示例答案与依据，不先测试 |
| “会基本定义，考我一道” | 给匹配范围的新情况，不强制重新入门 |
| “太难了，我不知道” | 补材料或拆细，不创建错误作答记录 |
| 只背出定义或点击了例子 | 不记为已掌握 |
| 同题已经看过答案 | 不计新的独立验证 |

原书的个别科学解释和例子也需学科核验，不能因引用书籍就当作无争议事实。例如OCR公式存在明显漏项，线性与正比例的表述需要按领域澄清；本插件采用教学流程，不复制这些具体知识作为判分标准。
